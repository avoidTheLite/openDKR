# Shared Glossary

- term: domain
  definition: A bounded documentation and decision surface owned by a team or capability area.
  synonyms: capability, area
  used_by_domains: all

- term: route
  definition: A deterministic mapping from intent to target destination plus required context.
  synonyms: path, dispatch rule
  used_by_domains: all

- term: adjudication
  definition: Resolution process used when deterministic routing confidence is below threshold or ambiguous.
  synonyms: tie-break, escalation decision
  used_by_domains: all

- term: function-first name
  definition: Artifact naming scheme where deterministic function stem appears before optional codename suffix.
  synonyms: semantic prefix, parseable stem
  used_by_domains: all

- term: codename suffix
  definition: Optional lore-friendly alias appended after `--` that never changes routing behavior.
  synonyms: alias, display name
  used_by_domains: all
